## 🛠️ How to Start the Servers (Reference)

If you ever need to restart the servers manually in separate terminals:

### 1️⃣ Backend Server (Laravel)
```bash
php artisan serve --port=8000
```
Runs at: [http://localhost:8000](http://localhost:8000)

### 2️⃣ Frontend Server (React + Vite)
```bash
cd client
npm run dev
```
Runs at: [http://localhost:5173](http://localhost:5173)
